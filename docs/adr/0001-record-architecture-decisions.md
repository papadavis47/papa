# 0001. Record architecture decisions

- **Status:** Accepted
- **Date:** 2026-10-11

## Context

Papa is a learning project built in public. The reasons behind its design matter as much as the code, both for future me and for anyone reading the repository.

## Decision

Record each significant decision as a short Markdown file in `docs/adr/`, using the template in `0000-template.md`.

## Consequences

Decisions are discoverable and reviewable in pull requests. Each one costs a few minutes to write.
